# TurinTech AI

> TurinTech AI builds Artemis, a code and AI optimization platform that searches configuration spaces across models, runtime, hardware, and source code to make production AI systems and software faster, cheaper, and more reliable without changing the existing stack. Artemis is driven through the Artemis CLI; TurinTech also offers evoML for automated machine-learning model building. Access uses an API key (ARTEMIS_API_KEY). Backed by Speedinvest.

## Products
- [Artemis](https://www.turintech.ai/): Optimization platform for production AI and software (AI inference, agentic software, latency-critical infrastructure, planning & scheduling).
- [evoML](https://www.turintech.ai/): Automated machine-learning model building — "from the data you have to the models you need."
